# 狼人杀术语表 (Glossary)

> 目的：收录狼人杀对局中的常用"黑话"，作为领域知识喂给 AI 玩家（issue #20），帮助 AI 理解他人发言、并用地道的语言组织自己的发言。
>
> - 术语的机制含义以本项目规则为准（BRD：`werewolf_business_requirement_document.md`），与桌面主流玩法不同处标注【本项目】。
> - 配套的打法与推理见 `strategy.md`。

## 1. 阵营与身份

- **好人阵营**：神 + 平民的统称，目标是投出所有狼人。
- **神（神职）**：有技能的好人——预言家、女巫、猎人、守卫、通灵师。
- **民（平民 / 村民 / 闲民）**：无技能的好人，靠发言和投票参与游戏。
- **狼人阵营 / 狼队**：所有狼人（含狼枪、机械狼等变体狼）。夜间睁眼互认、共同定刀。
- **小狼**：普通狼人，区别于狼枪、机械狼等带技能的狼。
- **不睁眼狼**：不与狼队一同睁眼、独立行动的狼。【本项目】机械狼即不睁眼狼，不参与狼队私聊与共同定刀。
- **独狼**：场上只剩一只狼。【本项目】其他狼全灭后机械狼进入独狼状态，每晚独立刀人。
- **屠边**：胜负规则（本项目默认）——狼人杀光**所有神**或**所有民**（任一边）即获胜；好人杀光所有狼获胜。
- **屠城**：可配置的胜负规则——狼人须杀光所有好人才获胜。
- **边**：屠边语境下的"神边 / 民边"，即狼人主攻的一侧（刀神 or 刀民）。
- **坑（狼坑 / 神坑 / 民坑）**：板子中某类身份的席位数。"找齐狼坑" = 推理出全部狼人所在位置。
- **板子**：一局的角色构成与规则配置（如"9 人预女猎"）。
- **底牌（身份牌）**：玩家的真实角色。
- **明牌**：公开亮明自己的真实身份（如猎人翻牌）。
- **法官（上帝）**：主持流程、掌握全部信息的裁判。【本项目】由系统（引擎）担任。
- **上帝视角**：全知视角。玩家发言若流露出不该知道的信息，就是"上帝视角发言"（穿帮）。
- **视角**：某玩家基于自身已知信息所能看到的局面。"从我的视角 X 是好人"；发言内容超出自己应有的信息量称"视角错误 / 穿帮"。

## 2. 查验与身份信息

- **查验（验人）**：预言家 / 通灵师夜间查看一名玩家的身份。预言家得"好人 / 狼人"阵营结果；【本项目】通灵师得**具体角色名**。
- **金水**：被（自称）预言家公开宣布查验为"好人"的玩家。"3 号是我的金水"。
- **查杀**：被（自称）预言家公开宣布查验为"狼人"的玩家。"我发 5 号查杀"。
- **银水**：被女巫解药救活的玩家——女巫视角的确认好人。
- **假金水 / 假查杀**：悍跳狼报出的虚假查验结果（常给狼队友发金水、给真神或好人发查杀）。
- **报查验**：跳预言家 / 通灵师者公布昨晚（及历晚）的查验结果。
- **盲验**：没有任何发言信息时的查验（首夜必然是盲验）。
- **铁**：确定无疑的身份判断。"这个位置铁好人""他俩必有一狼，铁的"。

## 3. 警长竞选与警徽

- **警长**：警徽持有者。放逐首轮警徽计 **1.5 票**，有**归票权**并**安排白天发言顺序**；决胜轮警徽降为 1 票。
- **上警**：报名参加警长竞选，成为候选人。
- **警上 / 警下**：候选人群体 / 未上警的玩家群体。也作方位词："警上发言""警下投票"。
- **退水**：候选人退出竞选。【本项目】任意时刻可退水；退水者不参与警长投票；退到只剩一人则该人自动当选。
- **警徽流**：跳验人神职（预言家 / 通灵师）者在竞选发言时预告的后续查验计划（"今晚验 X、明晚验 Y"），并约定死后警徽的处理方式来传递查验结果——常见约定：**移交警徽给查验目标 = 他是金水；撕掉警徽 = 查杀 / 无信息**。核心作用是"人死了信息还能传出来"。
- **移交警徽**：警长出局时把警徽交给指定存活玩家（其成为新警长）。
- **撕警徽**：警长出局时销毁警徽，此后本局无警长。
- **警徽流失**：竞选未产生警长（全员上警 / 全员退水 / 决胜轮再平票等）。
- **归票**：放逐投票前，警长公开表态——**归单人**（警徽 1.5 票投向某人，不可弃票）或**归多人上 PK**（带多人进决胜轮，警徽降 1 票）。广义上也指意见领袖号召集中投票。
- **PK（决胜轮 / PK 台）**：平票时最高票并列者依次发言、由其余玩家复票的环节。"上 PK 台"。
- **1.5 票**：警徽在放逐首轮的投票权重。

## 4. 发言与表态

- **跳（起跳）**：公开声称自己是某身份。"跳预言家""跳女巫"。
- **悍跳**：狼人假冒神职（通常是预言家 / 通灵师）强势起跳，争夺警徽和话语权。
- **对跳**：两人（或多人）声称同一身份——其中必有假跳。
- **表水**：声称 / 表现自己是普通好人（民）。"表个水"。
- **划水**：发言空洞、无信息量、不表态（常被视为狼的嫌疑痕迹，"划水狼"）。
- **踩**：发言中把某人往狼人方向评价。"踩他一脚"。
- **捞**：为被怀疑的玩家辩护、往好人方向评价。"把 7 号捞一下"。
- **抿**：凭语气、细节和直觉判断身份（区别于逻辑硬推）。"我抿他是个民"。
- **盘（盘逻辑 / 复盘）**：梳理发言、票型、死亡等信息做身份推理。
- **站边**：对跳局中选择相信其中一方。"我站 3 号的边"。
- **贴脸**：不加掩饰地当面认定对方身份。"贴脸打他狼"。
- **带节奏**：主导舆论、引导全场怀疑方向（好坏皆可用，狼带偏节奏是核心手段）。
- **抬轿**：发言为某人（常为悍跳狼）助攻、抬高其可信度。
- **倒钩**：狼人公开站边真预言家（或好人视角发言）骗取信任、混入好人阵营，关键轮反水（"倒钩狼"）。
- **冲锋**：狼人带头攻击真神、为悍跳队友开路（"冲锋狼"）。
- **深水（深水狼）**：全程发言中立温和、隐藏极深的狼。
- **反水**：先站边某方、后倒戈。
- **聊爆**：发言漏洞百出，把自己聊成狼 / 暴露真实身份。
- **痕迹**：发言或行为中暴露身份倾向的细节。"找痕迹""这是个狼痕迹"。
- **穿帮**：发言暴露了自己视角不该有的信息（如民说出只有狼才知道的事）。
- **前置位 / 后置位**：发言顺序靠前 / 靠后的位置。后置位掌握的信息更多、发言压力也更大。
- **挤身份（挤压）**：用发言逼迫某人表明身份，压缩其模糊空间。
- **挡刀**：好人（多为民）发言强势、伪装神职，吸引狼刀以保护真神。
- **抗推（扛推）**：被全场怀疑、面临被投出局。"抗推位" = 当天最可能被投出去的位置。

## 5. 夜间行动

- **刀**：狼队的夜间击杀。"刀口" = 被刀的目标；"首刀" = 第一夜的刀口。
- **空刀**：狼队夜里不杀人。【本项目】AI 狼队投票平票 / 无人投票也会导致空刀。
- **自刀**：狼刀自己人（含刀自己），常为骗女巫解药（做银水身份）或制造"被刀 = 好人"的假逻辑。
- **平安夜**：天亮宣布无人死亡的夜晚（被救 / 被守 / 空刀所致）。
- **双死**：一夜死两人（如同刀同毒；【本项目】机械狼大刀夜也是双刀）。
- **奶**：女巫用解药救人。"奶了刀口""奶穿"（救错 / 白救）。
- **毒**：女巫用毒药杀人。【本项目】被毒者默认不能开枪（猎人 / 狼枪禁枪）。
- **同守同救**：守卫守护与女巫解药同夜作用于同一人 → 该玩家**仍然死亡**。【本项目】默认开启，仅对狼刀。
- **空守**：守卫不守任何人。
- **自守**：守卫守自己（合法）。
- **连守**：连续两晚守同一目标——【本项目】禁止（含自守）。
- **空过**：夜间技能选择不使用、跳过（女巫不用药、通灵师不验等，视规则允许）。
- **验枪**：【本项目】每晚法官私下告知猎人"当前能否开枪"（是否带毒被禁枪）。
- **吞毒**：【本项目】夜里被毒的狼在死讯公布前（警长竞选期间）自爆，公开死因只显示自爆，毒被"吞掉"——外界不知女巫已用毒。
- **睁眼 / 闭眼**：法官夜间指令，"狼人请睁眼"等。

## 6. 白天、投票与放逐

- **放逐（推）**：白天投票让某人出局。"今天推 5 号"。
- **票型**：一轮投票的分布情况，复盘的重要客观信息（狼队常抱团冲票或刻意分票）。
- **跟票**：跟随他人的表态投票。
- **冲票**：集中票数强行推某人出局。
- **分票**：故意分散投票（狼避嫌、或好人意见不一时）。
- **弃票**：不投任何人。
- **平票**：最高票并列。【本项目】进入决胜轮（PK）复票；决胜轮再平票则本轮无人出局。
- **遗言**：出局玩家的最后发言。【本项目】白天出局（放逐、枪杀）有遗言；夜死仅**第一夜**有遗言（多人死亡时顺序随机）；自爆无遗言。
- **自爆**：狼人白天主动亮明狼身份立即出局——当天白天立即结束、跳过剩余发言与投票直接入夜，无遗言。竞选期间自爆会中断竞选（顺延至次日；次日再爆则本局永久无警徽）。
- **翻牌**：猎人（或狼枪 / 学猎人的机械狼）出局时亮明身份、尝试发动开枪。
- **带走**：开枪击杀。"翻牌带走 5 号"。
- **不翻牌（焖牌）**：猎人出局时选择不亮身份直接离场，不暴露任何信息。
- **枪口**：开枪的目标指向。"枪口对准查杀位"。
- **绑票（绑票胜利）**：【本项目】场上**可睁眼狼人数 ≥ 存活好人数**时，狼队掌握票权、直接判狼人胜（引擎自动判定；机械狼不计入可睁眼狼）。
- **拍刀**：【本项目】狼人白天主动明牌、要求提前结算：按强制流程模拟到底，狼仍胜则狼胜，否则好人胜（拍错=送）。

## 7. 本项目板子与特殊角色

- **9 人预女猎**：3 狼 vs 预言家 / 女巫 / 猎人 + 3 民。无守卫。
- **12 人预女猎守 + 狼枪**：3 狼 + 狼枪 vs 预女猎守 + 4 民。
- **12 人通灵机械狼**：3 狼 + 机械狼 vs 通灵师 / 女巫 / 猎人 / 守卫 + 4 民。
- **狼枪 (WolfGun)**：狼阵营的"猎人"——出局时可开枪带人；但**带毒或自爆**不能开枪（默认）。
- **通灵师 (Psychic)**：升级版预言家——每晚查验一名玩家的**具体角色名**（如"女巫""机械狼"）。
- **机械狼 (MechanicWolf)**：不睁眼狼。核心技能**学习**（全局一次、目标须为存活玩家）：获得所学角色的能力并**伪装**成该身份（通灵师验之显示所学身份；未学习则显示"机械狼"；伪装当晚即生效，主动技能次晚生效）。其他狼全灭后每晚**独立刀人**。
- **大刀（破盾刀）**：机械狼学狼人所得的一次性刀——默认无视守卫守护与女巫解药（必杀），发动当晚共刀两人（大刀 + 普通刀）。
- **毒反弹**：【本项目默认】机械狼学守卫后，若守护目标被女巫毒，则守住该目标且毒**反弹毒死女巫**（真守卫无此能力、也挡不住毒）。
- **明面存活**：竞选先于夜间死讯公布——前一夜死亡但死讯未公布者，竞选期间仍照常上警 / 发言 / 投票。
