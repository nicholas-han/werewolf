# 负面清单：AI 常见错误 (Anti-Patterns)

> 发言与决策前对照自查。

## 通用错误

- **上帝视角穿帮**：说出身份不该知道的信息（如平民说"狼队今晚刀了 P3"、好人不推理直接断言谁是狼）→ 发言前自问"这句话我的身份能知道吗"。
- **口径漂移**：与自己此前发言矛盾（昨天说 P5 像狼，今天无理由改口捞他）→ 改口须给出新信息作理由，否则维持原口径。
- **复述规则/流程**：把规则说明当发言念 → 只讲判断、推理和**站边**，规则人人都知道。
- **重复发言**：把昨天的话再说一遍，没有新信息 → 每轮发言要有增量：新查验、**票型**分析、或对昨夜死亡的解读。
- **空泛发言**："我再听听/我没有信息"式**划水** → 至少给出当前的怀疑排序和理由；划水本身就是狼痕迹。
- **发言与投票矛盾**：嘴上**捞**人票却投他 → 票跟嘴走；确要变票先在发言里说明。
- **把接到警徽当金水铁证**：接徽 ≠ **金水** → 必须按警长生前的**警徽流**约定反解（见 strategy.md §1.4），飞给**外置位**的警徽不保真。
- **乱弃票**：无理由**弃票**等于放弃好人票权 → 只在"投谁都可能送"的极端局面弃票，且要说明理由。
- **引用不存在的信息**：编造没发生过的查验/发言/票型 → 只引用对局记录里真实出现过的事件，记不清就不引用。
- **数字算错**：**狼坑**/**绑票**临界算错 → 表态前先数清场上存活与出局身份、剩余狼坑，再谈"还差几刀/几票"。
- **遗言浪费**：出局时只顾抒情、不留信息 → **遗言**要交代手上的硬信息（查验、**银水**、**验枪**、守护记录）+ 明确的站边与投票建议。

## 狼人专用
<!-- knowledge: role=Werewolf,WolfGun,MechanicWolf -->

- **说漏狼队信息**：白天引用夜聊内容、直接喊出队友身份 → 夜聊一个字都不能带出来，评价队友要装作不认识。
- **忘记假身份口径**：**悍跳**后忘了自己报过的金水/**查杀**/警徽流 → 每天发言前回顾已公开的假口径，新发言与之自洽、按警徽流顺延兑现。
- **票型暴露**：狼队每轮整齐抱团冲同一人 → 有意**分票**、安排**倒钩**票；**弃子**可反投队友做身份，避免复盘一抓一串。
