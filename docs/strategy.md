# 狼人杀基本逻辑与策略 (Strategy Basics)

> 目的：狼人杀的基本打法、惯用策略与推理模式，作为领域知识喂给 AI 玩家（issue #20），提升其对局水平。术语见 `glossary.md`。
>
> 所有策略以本项目规则为准（BRD）：屠边胜负、女巫**全程不可自救**且每晚最多一瓶、**同守同救=死**、被毒者**禁枪**（且法官不告知禁枪原因）、自爆立即终结白天、第一夜死者才有夜死遗言等。与主流桌面打法有流派分歧的地方按"一般原则"给出，可在此基础上调整。

## 0. 总纲：两条阵营公理

- **好人的核心资源是信息**。好人发言的目标是产生真实信息（查验、票型、行为逻辑）、传递真实信息、并识别狼的假信息。好人之间没有理由互相欺骗（民挡刀等战术伪装除外）。好人每一天的任务可以概括为：**找到真神 → 相信真神的信息 → 投出狼**。
- **狼人的核心资源是身份的隐蔽 + 信息优势**。狼互知身份（全场唯一的"确定信息集团"），发言目标是制造假信息、稀释真信息、把水搅浑；投票目标是形成局部人数优势。屠边只要求杀光一边——**刀神**（斩首技能位）或**刀民**（拼票数收绑票）二选一，狼队应明确走哪条路线。

## 1. 警长竞选：第一天最重要的博弈

### 1.1 为什么要争警徽

- 机制收益：放逐首轮 1.5 票 + 归票权 + 安排发言顺序。
- 更大的收益是**公信力**：警徽自带背书，好人警长能组织归票收狼，狼警长能名正言顺地带偏节奏。
- 【本项目】第二夜起夜死无遗言——夜里被刀的警长虽无遗言，但仍有**移交/撕警徽**动作。对验人神职来说，警徽是"死后还能说一次话"的唯一通道（见 1.3 警徽流）。

### 1.2 谁应该上警

- **预言家 / 通灵师：必上警**。验人位的信息需要警徽的公信力放大；首夜已有一验，上警报查验 + 报警徽流是标准动作。不上警的"预言家"后跳时公信力大打折扣。
- **女巫、猎人、守卫：一般不上警**，保持低调避免吃刀；技能位的价值在夜里和关键时刻，不在警徽。局势需要时（如警上全是狼脸）可上警搅局，但要做好被刀准备。
- **民：可适度上警**。作用是撑起警上人数、观察对跳、必要时挡刀；被验人神职盲验到也等于帮好人排坑。
- **狼队：通常派 1–2 人上警**——悍跳位争警徽，冲锋/抬轿位助攻。狼全员缩警下等于把警徽白送真神。

### 1.3 警徽流：用死亡传递信息（验人神职的标准动作）

- 竞选发言模板：**报昨夜查验结果**（金水或查杀）+ **报未来 1–2 晚的查验计划**（"今晚验 X、明晚验 Y"）+ **约定警徽的死后含义**。
- 常见约定："我若今晚被刀，警徽**移交**给今晚的查验目标 = 他是金水；**撕警徽** = 他是查杀（或我没验到信息）"。这样即使预言家夜里被刀（第二夜起连遗言都没有），查验结果仍能传递给好人。
- 通灵师的警徽流同理，且信息量更大——验的是具体身份，可以直接点出"机械狼"。
- 警徽流也是**鉴别真假预言家的材料**：真预言家的验人计划有针对性（验警下发言可疑者、验关键表态位）、前后自洽；悍跳狼编的警徽流常经不起追问（为什么验他？后续结果对不上）。
- 悍跳狼也必须报警徽流（不报直接暴露），所以好人不能只看"有没有警徽流"，要看**质量与后续兑现**。

### 1.4 退水与警下站边

- 非验人神职上警后，若判断真预言家已可信，应**退水让票**，把警徽送给真神（【本项目】退水者不投警长票，退到只剩一人自动当选）。
- 警下好人投警长票就是**第一次公开站边**：认真比较对跳双方发言（见 3.1），票投更像真神的一方。乱票、票型和发言不一致，是复盘时的狼痕迹。

### 1.5 自爆与竞选的攻防（本项目规则）

- 竞选完成前狼自爆 → 竞选**中止顺延**到第二天；**第二天再有狼自爆 → 本局永久无警徽**。狼可以用"连环自爆"炸掉警徽，代价是两条狼命——通常只在真预言家碾压警上、警徽必失的局面才值得。
- **警上自爆吞毒**：夜里被女巫毒的狼，若在死讯公布前自爆，公开只显示"自爆"，毒讯息被吞——好人不知道女巫用过毒，女巫队友信息也被浪费。狼夜里被毒不知情，但狼可以推断"我方今晚可能被毒"的场合主动爆（如队友已被查杀、自己聊爆）。
- PK 台上两名候选人之一自爆 → 另一人**自动当选**（第一天）。狼用自爆送对跳好人警徽是亏的；反之真预言家 PK 遇到对方自爆，等于不战而胜。

## 2. 各角色基本打法

### 2.1 预言家（9 人板 / 12 人守卫板）

- **首夜必然盲验**（夜在任何发言之前）：随机或按座位习惯验即可，验出什么都是信息。
- 从第二晚起**验关键位**：警上对跳的对手方金水/查杀链上的人、发言领袖、票型可疑者、抗推位。不验已确认位（银水、已翻牌的猎人等）——每晚只有一验，浪费一验等于帮狼。
- **必上警，报查验 + 警徽流**（见 1.3）。遇悍跳不要慌：真预言家的优势是信息会持续自洽，比拼发言逻辑、警徽流质量，并在后续几天用新查验压垮对方。
- 被查杀 / 被冲时：坚持输出信息，把每晚查验讲清楚；只要好人跟上节奏，狼的假信息总会露馅。

### 2.2 通灵师（通灵机械狼板）

- 打法同预言家：**必上警、报查验（具体身份）、报警徽流**。
- 具体身份查验自带排坑效果：验出"平民"也压缩了神坑与狼坑的组合空间，验出"女巫/猎人/守卫"等于帮该神做了身份铁证。
- **警惕机械狼伪装**：未学习的机械狼验显"机械狼"（最高价值信息，直接公布带队推）；已学习的显示所学身份——所以"验出女巫"≠铁女巫，若场上出现**两个同身份**（如双"女巫"），优先怀疑其一是学了该身份的机械狼，用行为与技能兑现情况交叉验证。
- 验人优先级：怀疑是机械狼的位置 > 关键表态位 > 排坑。

### 2.3 女巫

- **硬约束（本项目）**：全程**不可自救**；每晚最多用一瓶；**用过解药后不再获知刀口**；同守同救=死。
- **首夜解药**：主流打法是**首夜奶刀口**——解药越晚价值越低（用掉才停止获知刀口这一条反过来说明：不用就一直看得到刀口，但救人窗口稍纵即逝），且首刀常是神。风险有二：狼**自刀骗药**（首刀位后续行为要持续观察）；12 人板**同守同救**（守卫若也守了刀口，救=害死他）。一般原则：9 人板首夜奶；12 人守卫板首夜奶前要掂量守卫是否会守热门刀口。
- **毒药**：留给"确定的狼"——被查杀且自己认可逻辑的、悍跳暴露的、聊爆的。不确定宁可不毒：毒错神是双重灾难（少一神 + 被毒者禁枪，毒猎人等于废掉一支枪）。后期毒药是好人翻盘的最后资源。
- **身份隐藏**：女巫是狼的重点刀口，不轻易跳。**银水**（救过谁）是关键时刻的硬信息——某"预言家"给你的银水发查杀，他必是悍跳狼，这是女巫视角的秒杀级判断。
- 空刀/平安夜之夜你掌握独家信息（知道是救下了还是根本没死人），复盘时择机使用。

### 2.4 猎人

- **威慑位**：狼刀猎人要吃一枪，所以狼倾向用毒处理猎人（毒=禁枪）或把猎人留到后期。猎人可适度**表现存在感**逼狼忌惮，但不轻易明跳。
- 【本项目】**每晚验枪**：法官私下告知"当前能否开枪"。被告知**不可开枪 ≈ 你今晚将带毒出局**——这是重大信息（女巫或机械女巫的毒在你身上）。据此可以：天亮后视局面公开这一信息坐实"有毒在场"，或忍住不暴露女巫用毒痕迹。
- **枪口选择**：优先带走"确定狼"——查杀位、悍跳位、聊爆位；没有确定信息时带走自己视角最像狼的。**不要**带走未被证伪的跳神位。
- 被放逐时**翻牌开枪即自证**（真猎人有枪）；夜里被刀则天亮翻枪。开枪只能乱枪时，**不翻牌**保留信息也是选项（少用）。
- 12 人狼枪板注意：**枪≠好人**——狼枪也有枪（见 4.2），翻牌开枪不能单独作为好人铁证。

### 2.5 守卫

- **硬约束（本项目）**：挡不住毒；不可连守（含自守）；同守同救=死。
- 核心工作是**猜刀口**：跳出来的真预言家是狼刀首选 → 守卫的主线是保护验人神职，但受"不可连守"限制只能**隔晚轮守**（预言家 / 其他神 / 自己轮换）。
- **首夜**：无信息，自守、空守或凭感觉守皆可；主流是自守或空守（避开同守同救的概率）。
- **同守同救规避**：女巫大概率救首刀 → 守卫首夜不守"热门刀口"反而更安全；从第二晚起女巫若已用解药（观察白天信息推断），守卫可放心守热门位。
- 守卫全程隐藏身份，平安夜之后也不急着跳——"谁守中了"是你的独家信息，留到复盘对质时用。

### 2.6 平民

- 民的武器是**发言 + 投票**。认真听每一轮发言、盘票型、明确站边，做"有用的民"；划水的民会被当狼打。
- **挡刀**是民的隐性价值：发言强势、逻辑清晰的民会被狼误刀，等于替神挡刀。有意识地把自己活成"神脸"是高阶民的打法。
- **不乱跳神职**：民跳神会污染好人视角（战术挡刀除外，且要有收尾预案）。
- 被抗推时：逐天复盘自己的发言与投票自证逻辑一致性，争取验人位验自己（"今晚验我"是好人才敢说的话）。

### 2.7 狼人（普通狼）

- **开局分工**（狼队私聊时明确）：**悍跳位**（跳预言家/通灵师抢警徽）、**冲锋位**（攻击真神、给悍跳抬轿）、**倒钩位**（站边真神骗信任）、**深水位**（中立划水保存活）。12 人板 4 狼可齐配；9 人板 3 狼常取"悍跳 + 冲锋 + 深水"。
- **悍跳要点**：发查验挑"难证伪"的——给深水队友发金水（他发言会像好人）、给好人发查杀（最好挑发言有瑕疵的民）；警徽流编得有针对性、后续要圆得上。
- **刀法**（每晚定刀的优先级思路）：
  - **刀神线**：真预言家/通灵师 > 女巫 > 守卫 > 猎人（有枪，刀他要吃枪，常用毒解决或留最后）。要防守/防救：热门刀口容易被守被救，可**转刀**（刀口转移到银水外、守卫顾不到的位置）。
  - **刀民线**：找不到神或神难刀（被守）时，连刀民走屠民边，配合白天误推快速收**绑票**（可睁眼狼 ≥ 好人即自动胜）。
  - **自刀**：骗女巫解药（做银水=铁好人身份）或做"被刀=好人"逻辑；高风险（女巫不救就白亏一刀甚至折损）。女巫解药已用的情况下自刀无意义。
  - **空刀**：制造平安夜扰乱女巫/守卫的复盘（他们会以为救中/守中），也可配合"我方被查杀者明天要爆"的节奏；代价是浪费一晚，慎用。
- **自爆时机**：警上打不过真预言家 → 自爆中断竞选，消耗好人一个白天；次日再爆可废警徽（见 1.5）。后期"炸白天"可跳过对狼不利的放逐投票。**红线：最后一只狼（含机械狼在内全灭意义上的最后）自爆=直接判负**；若场上还有机械狼存活，最后一只普通狼自爆则游戏继续、由机械狼接管。
- **投票纪律**：狼票不要整齐抱团（复盘一抓一串）；安排倒钩票、分票做身份；弃子（已暴露的狼）可以反投队友做最后的信任背书。
- **拍刀**：白天算准"明牌走强制流程狼必胜"时可拍刀提前收局，算错=直接送——只在铁定赢的残局使用。

### 2.8 狼枪（12 人守卫板）

- 狼阵营的"猎人"：出局可开枪。天然打法是**悍跳猎人**或做一个"敢被推"的狼——被放逐反而白赚一枪（带走一个神或关键民）。
- 【本项目】**带毒或自爆不能开枪** → 狼枪**不要自爆**（浪费枪）；也要防被毒（被验枪机制无关，狼枪无验枪，出局才知道）。
- 枪口配合狼队节奏：白天狼队推 A、狼枪出局带走 B，形成一天双杀。
- 对好人的镜像提醒（复盘用）：本板"翻牌开枪"不再是好人铁证。

### 2.9 机械狼（通灵机械狼板）

- 定位：狼队的**暗子与后手**——不与狼队见面、不计入绑票，但计入"狼全灭"判负，所以只要机械狼活着，狼队推光了也没输。
- **学习选择**（全局一次、目标须存活、伪装当晚生效、主动技能次晚生效）：
  - **学女巫**：拿药水副本（以学习当刻女巫剩余为准——想拿全两瓶就要早学），后期一瓶毒等于多杀一神。
  - **学守卫**：本板默认**毒反弹**——守住被毒者且反杀女巫；伪装成守卫也极难被证伪。防守+反杀双收益。
  - **学通灵师**：获得验人能力（独狼期知道谁是神、刀法精准），且可**对跳真通灵师**搅乱好人视角。
  - **学猎人**：出局带人 + 伪装猎人（好人不敢轻易推"猎人"）。
  - **学狼人**：换一次性**大刀**（默认破盾必杀 + 当晚双刀），独狼期爆发收割最强。
  - **学平民**：纯伪装、最低调，技能收益为零，一般不选。
- **尽早学习**：未学习时被通灵师验到显示"机械狼"= 当场暴露；通灵师每晚都在验（且验在机械狼行动之后），**第一晚就学习**能把伪装窗口拉满。
- **独狼期**（其他狼全灭后）：每晚独立刀人 + 白天用伪装身份发言收割；持有大刀时挑"守卫守不住也救不下都无所谓"的关键晚双刀清神。
- 白天常规打法：深水，扮演所学身份融入好人，不抢节奏；狼队被推时甚至可以投狼队友的票做身份（反正互不相识，票型天然干净）。

## 3. 通用逻辑与推理模式

### 3.1 对跳怎么站边

依次比较：

1. **查验的针对性**：首夜都是盲验（随机可原谅），第二晚起真预言家验的是"场上关键位"，假的常验得没道理。
2. **警徽流质量与兑现**：前后自洽、能兑现的是真；改口、圆不上的是假。
3. **发言次序**：先给信息后盘逻辑的更像真神；只带节奏不给信息的可疑。
4. **金水/查杀链的行为**：真金水的后续发言投票应像好人；假金水（狼队友）会在票型上露馅。
5. **硬信息一票否决**：给银水发查杀的必是悍跳（女巫视角）；给已证实好人发查杀的同理。

### 3.2 票型分析

- 票是**客观信息**，比发言可信。复盘每轮"谁投了谁、跟谁的票"。
- 狼票特征：关键轮集中冲好人、保狼队友；"倒钩票"（狼投狼）多发生在该狼已暴露/被弃时，用来给活狼做身份。
- 发言与投票不一致（嘴上捞人票却推他）是高权重痕迹。

### 3.3 刀口分析（死亡信息）

- **刀口即狼的视角**：狼刀谁，说明狼怕谁/想嫁祸谁。跳神者被刀 → 大概率是真神（但要防自刀做局）。
- **平安夜**拆解为三种可能：女巫救了 / 守卫守中 / 狼空刀，结合女巫守卫后续的暗示与狼的节奏推概率。
- **死因组合**：一人双死因（同刀同毒）说明女巫和狼同时点了他——女巫视角这是"我毒的人恰好被刀"，复盘价值极高。
- 警徽的移交/撕毁按生前约定解读（见 1.3）；第一夜多死时遗言顺序是随机的（本项目），顺序本身无信息。

### 3.4 身份挤压与排坑

- 板子构成是公开的（如 12 人 = 4 狼 4 神 4 民）：每确认一个身份，剩余坑位组合就收窄。
- 主动**挤身份**：逼模糊位表态"你到底是什么"，再用后续信息证伪。
- **排坑法**：枚举"谁真谁假"的身份组合假设，用票型、刀口、查验逐一排除矛盾组合，收敛到自洽的狼坑分布。发言时讲清楚自己的排坑过程，好人才能跟上并纠错。

### 3.5 信息可信度的一般原则

- **客观事件 > 主观发言**：死亡、票型、警徽动向不会说谎；发言都可能是表演。
- 区分**蠢和坏**：发言前后矛盾且矛头总是指向好人 → 坏（狼）；单纯没逻辑但无倾向 → 可能只是蠢（民）。好人不要急着推"蠢"，优先推"坏"。
- 越后置位的发言越要防"顺风倒"（听完全场再贴大众的和事佬发言，常是深水狼保命姿势）。
- 自己视角的铁信息（银水、验枪结果、守中记录）在**最能翻转局面的时刻**打出，过早暴露=给狼修正机会。

## 4. 分板子速查

### 4.1 9 人预女猎

- 3 狼 vs 预/女/猎 + 3 民；无守卫 → 女巫解药是唯一防御，狼刀口自由度高。
- 节奏极快：民只有 3 个，狼连刀民 + 好人误推一次就接近屠民边；好人必须速立真预言家、每天的放逐都不能浪费。
- 女巫首夜奶的价值最高（无同守同救顾虑）。

### 4.2 12 人预女猎守 + 狼枪

- 4 狼（含狼枪）vs 预/女/猎/守 + 4 民；有守卫 → 前期平安夜概率高，狼要多考虑转刀。
- **本板核心反直觉点：枪 ≠ 好人**。狼枪的存在使"被推后翻牌开枪"不再自证好人；复盘枪口指向（带走的是好人还是狼）才是判断依据。
- 同守同救=死：平安夜与非常规死亡的复盘要把这条规则算进去。

### 4.3 12 人通灵机械狼

- 4 狼（3 普通 + 机械狼）vs 通/女/猎/守 + 4 民。
- 通灵师验具体身份，好人信息上限极高；平衡项是机械狼的伪装、毒反弹与大刀。
- **狼全灭才算好人赢**：推光 3 只普通狼游戏未必结束——机械狼接管夜刀，好人要从"跳过身份的人"里找伪装者（对跳过的同身份位、技能兑现存疑的位）。
- 双同身份跳（如两个"女巫"）→ 优先怀疑其一是学习后的机械狼。
- 女巫注意：你的毒可能被"学守卫的机械狼"反弹——毒人前评估目标被机械狼守护的可能性（本板默认反弹致死）。
